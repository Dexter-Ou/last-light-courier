# Try a delivery

Download the [source ZIP](https://codeload.github.com/Dexter-Ou/last-light-courier/zip/8ef30a7fd89b1c8b3054d7eb7bda6815b7a49c6d),
extract the entire folder, then open `index.html`. Keep `game.js` and `ui.js` beside it.
GitHub's file view displays source rather than playing the game. You can disconnect
after downloading: the game has no external resources or telemetry.

Start with **First delivery**. Collect the parcel and reach E. Try **The detour**
next, then **One last charge**. A charger refills your battery only once; undo
lets you revise a route without starting over. There is no timer or saved progress.

If you want to share feedback, [open an issue](https://github.com/Dexter-Ou/last-light-courier/issues/new).
A GitHub account is required to submit an issue. Useful details:

- Which route did you try, and did you finish or stop?
- Which rule, symbol or control was unclear?
- Was a choice interesting or frustrating? Describe the moment.
- For a bug: browser/device, moves, expected result and what happened.

Feedback is optional. Do not include personal data or private files. No information
is collected automatically. Keyboard and buttons were checked in headless Chromium
on Linux; other browsers and physical touch devices have not been tested.
